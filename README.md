# Pawmail releases

Signed builds of Pawmail for macOS and Windows, and the feeds the apps
read to update themselves. The source code is not here.

- **macOS:** `appcast.xml` on this branch is the Sparkle feed. Each
  release's zip is a notarized `Pawmail.app`.
- **Windows:** Velopack packages in the releases.

Download the latest version from
[Releases](https://github.com/gr08/pawmail-releases/releases). Pawmail then
keeps itself up to date (Pawmail › Check for Updates…).
